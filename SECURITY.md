# Security policy

Please don't open a public issue for a vulnerability. Report it privately on
GitHub instead: go to the **Security** tab of this repository and choose
**Report a vulnerability**.

Include:
- the affected package and version;
- what an attacker can do;
- the steps to reproduce.

We reply within 3 working days.

Fixes ship in the latest version of each package. Older versions are not
patched.
